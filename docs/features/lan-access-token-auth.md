# 局域网访问令牌体验优化

### 问题
文档仍称默认监听 0.0.0.0 并暴露未鉴权界面，与当前默认 127.0.0.1 及远程请求令牌校验实现不一致。用户也无法从文档获知局域网访问的实际启用方式。

### 原因
默认绑定地址曾在安全加固提交中改为 127.0.0.1，但相关指南未同步。现有 CODEXMATE_HTTP_TOKEN 鉴权能力没有形成完整的用户操作说明，终端安全提示也仍使用“无鉴权”旧描述。

### 修改点
site/guide/limits.md 更正默认监听地址与远程令牌要求。
site/guide/quick-start.md 增加局域网令牌启动命令和浏览器登录说明。
site/guide/start-here.md 更正默认访问边界与局域网启用方式。
site/guide/web-ui.md 增加局域网访问、浏览器 Basic Auth 与 API 请求头说明。
cli.js 优化监听所有网卡时的终端安全提示，明确无令牌时远程访问已禁用。
tests/unit/lan-access-auth-docs.test.mjs 增加文档与提示一致性回归。
tests/unit/web-run-host.test.mjs 修正默认绑定测试名称。

### 预期结果
默认启动保持仅本机访问。需要局域网访问时，用户能按文档配置访问令牌并完成浏览器登录；终端和文档均明确未配置令牌时远程请求会被拒绝，不再声称开放未鉴权界面。
验证：执行局域网访问文档、监听地址与鉴权回归及差异检查。
验证结果：局域网访问文档、监听地址与鉴权回归共 58 项通过；node --check 与 git diff --check 通过。
