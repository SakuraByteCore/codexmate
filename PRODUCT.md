# Product

## Register

product

## Users

Codex Mate serves developers and power users who work across multiple AI coding tools. They use the local CLI and Web interface to find previous conversations, inspect and export session records, manage provider configuration, edit shared prompt files, and coordinate repeatable tasks without moving local data to a required cloud service.

## Product Purpose

Codex Mate consolidates local AI coding records and configuration into one dependable workspace. Success means users can locate the session, file, provider, or task they need, understand the current state, complete the operation, and verify the result without unnecessary setup or loss of context.

## Brand Personality

Restrained, compact, trustworthy. The interface should feel like a mature local utility: calm under routine use, explicit about state and risk, and fast without becoming abrupt.

## Anti-references

Avoid noisy dashboard grids, decorative gradients, marketing-style hero treatments, cloud-account onboarding, hidden destructive actions, and controls that move or wrap unpredictably during frequent use.

## Design Principles

- Local-first transparency: show the real file, source, and state that an action affects.
- Task-first density: keep frequent operations compact without sacrificing labels, focus states, or touch targets.
- Familiar controls: reuse standard tabs, selects, buttons, popovers, and confirmation patterns.
- Predictable layout: preserve spatial relationships and prevent content from reflowing during state changes.
- Cross-agent consistency: present Codex, Claude, Pi, and other tool integrations through the same interaction vocabulary.

## Accessibility & Inclusion

Target WCAG 2.2 AA for text contrast, keyboard operation, visible focus, and semantic labeling. Maintain touch targets of at least 44 by 44 CSS pixels where space permits, support reduced-motion preferences, and never rely on color alone to communicate status or grouping.
