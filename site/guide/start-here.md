# 从这里开始

忘了某个方案是在 Codex 还是 Claude Code 里讨论的？Codex Mate 把不同工具的本地会话放到同一个浏览器中，让你查看、筛选并导出记录，不必逐个翻找目录。

## 适合谁

- 已有 AI 编程会话，想找回某次讨论或把记录整理成 Markdown。
- 使用多个编程工具，希望集中管理 Provider、Skills 和任务。

第一次使用先完成一件事：**找到一段已有对话，确认内容并导出。** 不必先理解全部模块。

## 它是什么 / 不是什么

- 它是本地运行的 CLI + Web 管理工具，不是新的模型，也不替代原编程助手。
- 它读取本地会话、管理本地配置，不要求 Codex Mate 云端账户，不收遥测。
- 本地运行不等于模型离线运行；模型请求仍由所配置的 Provider 处理。
- Markdown 导出用于阅读与归档，不代表在另一工具中恢复完整状态。各来源的操作限制见[会话指南](/guide/sessions)。

## 已有会话：先查看记录

按[快速开始](/guide/quick-start)任选一种方式安装，然后启动：

```bash
codexmate run
```

打开终端显示的地址，在「会话来源」选择有记录的工具，打开一条会话，点击「导出记录」。没有本地记录时，先在原工具中产生一段对话。

默认监听 `0.0.0.0:3737`，支持局域网访问并自动打开浏览器。仅本机访问可用 `codexmate run --host 127.0.0.1`；不开页面可用 `codexmate run --no-browser`。默认端口被占用时会尝试后续端口；显式指定不可用的 `CODEXMATE_PORT` 则会报错。

## 需要配置 Provider：再运行向导

```bash
codexmate setup
codexmate status
```

`setup` 是交互式配置向导，`status` 用于检查配置状态，不是查看已有会话的必经步骤。查看会话不要求先配置全部工具；这也不意味着所有 CLI 命令都只读，配置向导和管理操作会写入本地文件。
