# 会话管理

找回某次讨论，确认内容，再导出为 Markdown 留作项目记录。会话浏览器集中展示不同工具的本地记录；查看和导出不等于迁移完整智能体状态，主动删除则是另一类写入操作。

## 先找回一段对话

1. 按[快速开始](/guide/quick-start)启动，进入 Web UI 会话视图。
2. 在「会话来源」选择已有记录的工具，再按项目路径或时间缩小范围。可输入关键词并按回车检索；界面有检索入口不代表所有来源的记录格式都已经验证。
3. 打开会话，核对项目、时间和讨论内容。
4. 在「导出范围」选择最近 1000 条或全部可提取消息，再点击「导出记录」。打开下载的 Markdown 核对内容；截断说明会保留在当前会话预览中，可选择全部后重新导出。

关键词查询会显示实际扫描数与本次候选数。未完成时请缩小来源或项目范围；候选范围不等于全部历史记录。筛选无结果时可直接点击「清除筛选」。没有记录时先确认原工具在本机保存过会话，再刷新。配置 Provider 不会生成历史会话。

## 来源与存储位置

以下依据仓库 `0.1.28` 的来源选项和读取路径整理，表示当前实现有对应入口，**不是逐来源、逐 CLI 版本的运行验收矩阵**。环境变量或工具自身配置可能改变实际目录。

| 来源参数 | 工具 | 默认记录位置 |
| --- | --- | --- |
| `codex` | Codex | `~/.codex` 下的会话目录 |
| `claude` | Claude Code | `~/.claude` 下的会话目录 |
| `gemini` | Gemini CLI | `~/.gemini` |
| `codebuddy` | CodeBuddy Code | `~/.codebuddy` |
| `workbuddy` | WorkBuddy | `~/.workbuddy-ai/projects` |
| `pi` | Pi | `~/.pi/agent/sessions` |
| `opencode` | OpenCode | 数据目录中的 `opencode.db`，默认 `~/.local/share/opencode` |
| `zed` | Zed | Zed 数据目录下的 `threads/threads.db` |

OpenCode 导出的来源分支现已互斥，避免数据库读取结果被通用文件读取覆盖。各工具版本的存储格式仍可能不同，先用一条记录核对结果；来源出现在列表中不代表所有版本均已验证。

## CLI 导出

命令支持的来源值与上表一致。用实际会话 ID 替换 `YOUR_SESSION_ID`：

```bash
codexmate export-session --source codex --session-id YOUR_SESSION_ID
```

也可指定文件和输出位置：

```bash
codexmate export-session --source claude --file "./session.jsonl" --output "./session-notes.md"
```

默认最多提取最近 `1000` 条消息。需要取消数量上限时：

```bash
codexmate export-session --source codex --session-id YOUR_SESSION_ID --max-messages all
```

数量上限取消不等于无损导出：实现以提取后的消息文本生成 Markdown，并处理开头的系统消息。图片、工具调用状态和权限等不应被视为完整保留。导出文件用于阅读与归档，不能代替原始会话备份。

## 导出与转换的区别

Markdown 导出不要求在另一编程工具中恢复会话。现有会话转换仅面向 Codex 与 Claude，围绕文本消息生成目标记录，并有独立的消息数量限制。不要将其理解为无损迁移；目标原生 CLI 能否续接，需要按具体版本另行验证。

## 结构化交接与共享记忆

在会话的「会话交接」区填写目标代理与交接目标。生成后查看每条交接的路径、写入结果、耗时和读取状态。MCP 路径下点击「回退文件并复制卡片」，再粘贴到目标会话；复制不等于发送。

也可保存卡片 JSON：

```json
{"goal":"完成交接验证","completed":["已定位问题"],"blockers":[],"nextSteps":["执行定向测试"],"files":["lib/thread-handoff.js"]}
```

```bash
codexmate thread handoff YOUR_SESSION_ID --card card.json --target claude
codexmate thread list YOUR_SESSION_ID
codexmate thread fallback YOUR_SESSION_ID --handoff HANDOFF_ID
codexmate thread ack YOUR_SESSION_ID --handoff HANDOFF_ID --agent claude --evidence TARGET_SESSION_OR_RETRIEVAL_ID
```

先保存文件，再只读探测项目 `.mcp.json`、项目及用户 `.codex/config.toml`、用户 `.claude.json` 与 `.claude/settings.json`。识别 `uac` 等共享记忆服务，按原生工具 schema 选择单个 MCP。支持 `memory_write`、`set_memory` 等兼容写入工具；未知必填字段视为不兼容。不会新建共享记忆存储，不修改用户配置，不强塞目标提示词。

MCP 不可用或写入失败时明确提示文件路径，不自动重试写入。卡片与追加审计保存在 `~/.codexmate/threads/<hash>/`。审计记录 MCP、工具、耗时、结果、回退与读取确认；配置解析问题也会记录。连接用完关闭，不新增守护进程。

写入成功仅标记 `awaiting_read`，不是读取凭证。目标实际读取后才使用 `ack` 上报会话或检索标识；`read_confirmed` 表示附证据自报，不是独立验证。未上报时保持等待读取，不能断言目标一定没读。


会话详情的更新、路径复制、导出与删除仅显示图标。悬停查看操作提示；键盘和读屏保留操作名称。删除仍使用原有确认与回收站设置。

## 主动删除与清理

删除不属于首次查找与导出流程，也不是只读操作。当前 Web UI 的单条删除入口限制为 Codex、Claude 和 Pi；其他来源不能据此推断支持删除。

清理前核对来源、筛选结果和界面确认信息。回收站可配置，不能一概承诺删除都会进入回收站或一定可恢复；需要保留原始记录时先自行备份。回收站规则另见[设计边界](/guide/limits)。

## 上下文体检

打开会话浏览器中的记录，在详情顶部查看完整上下文的预估 Token 与堆叠条。统计覆盖保存的完整消息树，不限当前分页；支持上方列出的八种来源。

五类明细默认显示，无需展开：系统与规则、用户指令、模型文本与思考、工具输出与日志、代码块与 Diff。代码分段从所属角色中拆出，分类总和与总数一致。

- 健康：少于 32000 预估 Token。
- 偏重：32000 至 64000，包含两端。
- 膨胀：超过 64000。

界面保留总量、健康评级、构成条和分类统计；模型窗口参考独立显示。不显示膨胀热点列表、Top 5 排行或展开开关。后端保持原分析与节点查询接口兼容。

这些数字估算已保存的可读文本，不等同模型实际请求 Token 或费用。体检不会读取工具引用的文件，不修改会话。会话更新后点击刷新；读取失败时显示错误，不展示不完整统计。

## 用量分析与下一步

Web UI 还提供消息趋势和项目排行，帮助复盘使用情况。找回记录后，需要复用工作方式可看 [Skills 与提示词](/guide/skills-prompt)，需要管理配置可看[核心工作流](/guide/workflow)。

### 用量记录明细

在「Usage」展开「用量记录明细」后才读取会话文件。按所选 7 天、30 天或全部范围展示记录 Token 与缓存读取/写入；明细按 UTC 日期归属，旧图表与默认导出仍按会话更新时间归属。

Codex 使用累计用量的增量，重复快照不重复累计，计数重置后从新计数继续；缓存读取属于输入子集，不再加到总量。Claude/Pi 使用助手消息用量，重复消息 ID 的快照只累计新增部分；缓存读取与创建分别展示。明细当前适配 Codex、Claude、Pi，以及既有 JSON 格式的 Gemini 会话；其他来源列入未支持数量。

Gemini 读取 `type: gemini` 消息的 `tokens`，按消息 ID 去重；`input` 含缓存子集，`output` 仅为候选输出，`total` 保留上游总量（含思考与工具 Token），不把缓存再次相加。缓存创建未提供时显示未知；缺少 `total` 不猜总量。Gemini 新式 JSONL 会话尚未纳入现有发现与读取链，本轮不扩展该格式。缺失字段显示未知；缺失记录时间不猜日期。首次累计值归入首次记录日，记账事件不等于实际 HTTP 调用次数，结果不是供应商账单。

完整已保存文本估算复用上下文体检算法，单独统计扫描候选的全历史，不与记录 Token 相加，也不受明细日期过滤。缺少用量记录不代表消耗为零。显示扫描数量、无记录、未支持及失败数量；失败时保留已读取结果并标注不完整，刷新可重试。每次记录读取重新发现候选；缓存仅保存数值，未变化文件复用数值结果。文件更新自动失效，强制刷新重新读取。

CLI 默认输出保持不变；显式选择记录归属：

```bash
codexmate analytics export --attribution records --format json --from 2026-05-01 --to 2026-05-02 -o -
codexmate analytics export --attribution records --format csv --source codex -o usage-records.csv
codexmate analytics export --attribution records --format json --source gemini -o -
```

`records` 日期参数仅接受 `YYYY-MM-DD`，结束日期包含整日。JSON 包含明细、覆盖与估算；CSV 包含日期、来源、模型、输入、缓存读取、缓存创建、输出、总量、记账事件及会话数，未知分项留空。任一会话读取失败时拒绝导出不完整文件。日期过滤时无日期记录不进入日表，其 Token 数单列；全部范围保留空日期行。按模型过滤只作用于记录行，文本估算仍表示全部已扫描候选。

此功能只读会话，不读取工具引用文件、不调用模型、不接入价格或费用。发现的候选数量不等于磁盘上的全部会话。

### 费用参考（USD）

在 Usage 单独展开“费用参考（USD）”，按当前 7 天、30 天或全部范围读取记录。使用随应用发布的 [Wei-Shaw/model-price-repo](https://github.com/Wei-Shaw/model-price-repo) 基础文本 Token 单价快照；显示价格源更新时间和 commit，下载 JSON 包含源 SHA-256、分项单价、每行结果与覆盖数量。初始快照 commit 为 `5efca9b14c9ae3bafce4765434143eec289a741b`，包含 280 个模型。仅按完整模型 ID 匹配，不猜别名或历史计费供应商；应用更新时更新快照，不在打开页面时访问价格网站。

输入和缓存按来源语义计算：Codex/Gemini 的缓存读取从输入中扣除再按缓存单价计算；Claude/Pi 的输入、缓存读取与创建分别定价。基础单价不包含长上下文阶梯、服务层、缓存时长、工具调用或多模态附加费，结果不是账单。缺少用量、分项单价或模型价格时显示未知；Gemini 总量存在未归类思考/工具 Token 时不凑算费用。单价明确为零与缺失价格不同。

总额只在本次候选全部可定价且没有读取失败、未报告或未支持记录时显示；否则保留已知行小计和未知数量。覆盖仍受会话候选发现边界限制，不代表整台机器或供应商总账。原记录明细、图表和 CLI 默认导出保持不变；费用参考是独立只读入口。

## 会话工作台

### 收藏与备注

点击消息旁的收藏图标，填写备注与逗号分隔的标签。会话页“收藏”默认显示关键词搜索，在“更多筛选”中组合标签与项目绝对路径。点击“查看原文”核对来源；原记录失效时保留摘录。取消收藏只移除收藏元数据，不删除原消息。单条摘录上限 50000 字符，备注上限 4000 字符，标签最多 20 个。无原生行号的相同文本消息无法唯一定位时拒绝收藏；可从索引结果选择确切节点。

### 全文索引

在“全文索引”点击“更新索引”，按当前会话来源读取候选。默认每个来源发现最多 3000 条候选，API 支持 1–10000 的发现上限；现有来源扫描器仍有自身边界。范围不是全部历史。更新期间可取消，取消保留旧有效索引。点击“重建索引”强制重新提取当前来源；目录损坏时保留损坏清单，按全部来源重新发现候选。物理文件按 SHA-256 判断增量，数据库来源每轮重新提取。消息新增、替换或删除后需要刷新。

状态区显示整个索引目录的 UTC 更新时间，未知或未建立时显示未知。展开“搜索范围”查看当前来源的候选数量与发现上限；全部来源显示各来源记录。目录更新时间不是逐来源同步时间；来源缺少覆盖记录时提示更新索引。搜索完整仅指已索引候选，不能证明覆盖全部历史或新增消息。

搜索沿用上方来源、项目与角色筛选，独立输入关键词；结果展示命中片段与前后文，最多 100 条。点击“查看原文”定位准确节点，超出预览分页时在原文区展示完整节点。读取失败或范围截断会提示部分覆盖；原有会话搜索仍可使用。

### 跨会话证据包

在全文索引结果勾选“加入证据包”，跨来源与会话累计材料。材料篮只存当前页面，切换来源或会话保留，刷新清空；原会话、收藏与交接草稿不变。最多选择 100 条材料。

填写交接目标后生成证据包，按会话串行复用原草稿提取接口。生成时重新读取选定节点，对照选中时的文本 SHA-256；任何材料读取失败或内容改变都不输出完整包，保留选择供移除或更新索引后重新选择。Markdown 保留来源、会话、节点、原文路径、哈希与每条最多 800 字符的摘录。预览显示字符数，不代表模型实际 Token。

下载只写浏览器选定位置，不上传，不调用模型或启动 MCP。历史日志的通过/失败不是当前版本验收；模型自述仍待核对。包包含用户所选原文与路径，分享前检查预览。证据包独立于原单会话交接，不自动发送或覆盖草稿。

### 自动交接草稿

勾选消息，点击“生成交接草稿”。工具日志中的明确成功与失败进入对应字段；用户或模型的自述不会直接标为验证通过，含糊内容进入待确认列表。草稿保留来源证据，支持回看。生成不会发送，不启动 MCP；修改目标与后续步骤后使用原交接动作发送。发送时将所选证据作为可选元数据保存在交接文件中，旧卡片 JSON 与 CLI 保持兼容。

### 项目工作台

进入“项目工作台”，按完整路径聚合跨工具会话、收藏与交接，预览现有提示词文件。没有路径的记录进入未归属项目，同名目录与 worktree 默认独立。会话列表显示最近 100 条，候选发现上限与来源边界会限制范围。历史时间不等于当前文件、Git 或测试状态。

路径迁移后可显式保存“旧路径 → 新路径”映射；空目标解除映射，循环映射被拒绝。查看项目与预览提示词不改 Provider、权限或提示词文件；映射只写 Codex Mate 元数据。

### Git 改动关联（只读）

在项目工作台选择项目，展开“Git 改动关联（只读）”。读取当前仓库根目录、分支或游离 HEAD、HEAD、变更文件及最近 30 个提交；点击提交查看文件变更统计。最多列出 50 个当前变更文件，截断时提示。刷新 Git 重新读取；切换已展开的项目同步切换读取目标，不使用上一项目结果。

按会话更新时间与提交时间前后 24 小时生成“时间关联候选”；只关联相同完整项目路径的候选会话，不因同名目录合并 worktree。时间接近不证明该会话产生提交，不证明测试通过，也不代表提交时的真实工作区状态。路径映射后的旧路径记录不会冒充当前路径的直接关联。

不是仓库、路径不可访问、尚无提交、Git 不可用和读取失败各自显示状态。每条 Git 命令超时 5 秒、输出上限 256 KiB；超限或失败不展示部分成功。仅使用不加可选锁的 Git 读取命令，提交统计禁用外部 diff 与 textconv。不会安装 hooks、创建 checkpoint、提交、切换分支或上传会话。

### 模型窗口参考

在体检下方查看“模型窗口参考”，展开“设置模型窗口”编辑。窗口来自与会话模型匹配的记录元数据，或用户填写的正整数；未知窗口不猜值，多模型会话需选择比较对象。显示的是“历史文本 / 模型窗口（估算）”，不是当前请求占用、费用或剩余窗口。原有 32000/64000 固定评级不变。

估算占比达到 80% 显示偏高，达到 95% 显示高；超过 100% 不截断。提醒可关闭，偏好在重启后保留。点击交接只展开原有区域，不自动压缩、删除或发送。

### 存储与恢复

自有数据位于 `~/.codexmate/session-features/`：`bookmarks.json` 保存收藏，`projects.json` 保存显式映射，`preferences.json` 保存窗口与提醒偏好，`index/` 保存可重建索引。元数据写入校验修订号；冲突时刷新后重试，不覆盖其他修改。记录损坏时明确报错，不自动清空。回退代码不会删除上述数据或原始会话。
